# Review: Americas Regional Study Planner (GS-GE-KS2-003)

**Reviewer verdict:** Excellent curriculum metadata object; not yet a classroom-ready teaching output.

**Core diagnosis:** It defines the curriculum logic, but not the instructional choreography. It knows what the dance is about; it does not yet know the steps.

---

## Gap Analysis: 7 Identified Weaknesses

### Status key
- **Genuinely missing** — not in the model at all
- **Thin/present** — the model contains something, but it's insufficient
- **Already covered** — the model handles this adequately

---

### 1. A precise choice of region
**Status: Genuinely missing**

The planner offers five exemplars (Amazon, California, Patagonia, Caribbean, Andes) but does not select one. These are wildly different units — the climate, human geography, case studies, maps, misconceptions, vocabulary, visuals, and comparisons all change depending on the choice.

Without a single named region, the system cannot produce accurate core knowledge, a coherent narrative, lesson-specific maps and data, focused vocabulary, or meaningful assessment.

**What's needed:** A single named region with rationale. For example:
> Region selected: Amazon Basin, Brazil
> Why: strongest contrast with typical UK and European studies; rich links to climate, biodiversity, rivers, settlement, indigenous communities, land use, and environmental change.

**Verdict: This is the single biggest gap. Until it's fixed, the rest wobbles.**

---

### 2. A lesson-by-lesson knowledge model
**Status: Thin/present**

The planner *does* provide a session structure (`orientation → mapping → data_collection → analysis → comparison → evaluation`) and states "6 lessons." But these are process verbs, not actual lessons.

**What the model has:**
- A six-phase abstract structure
- KS2 question stems for place study
- A general assessment description

**What's missing for each lesson:**
- Lesson title
- Lesson objective
- Exact knowledge to be taught
- Disciplinary skill focus
- Key vocabulary for that lesson only
- What pupils produce
- How understanding is checked
- How it links to the next lesson

**Example of what's needed:**
```
Lesson 1 — Where is the region and what is it like?
Lesson 2 — Climate, biome, and physical features
Lesson 3 — River/landscape and how the environment works
Lesson 4 — Human geography: settlement, livelihoods, transport
Lesson 5 — Change, challenge, and different perspectives
Lesson 6 — Comparison with UK/Europe and final outcome
```

---

### 3. The exact final output
**Status: Thin/present**

The planner says: "Place study report combining map work, data presentation, descriptive and explanatory writing about geographical features and processes, and comparative or evaluative conclusion."

That is serviceable but mushy.

**What's needed:**
- Final product format (e.g. two-page booklet, poster, oral presentation)
- Expected length/complexity
- Mandatory components (labelled map, climate graph interpretation, physical features paragraph, human features paragraph, environment-shapes-life explanation, comparison with UK/Europe, conclusion answering enquiry question)
- Success criteria tied to the product
- Model examples at expected standard

---

### 4. Proper assessment design
**Status: Thin/present**

The planner *does* contain:
- A differentiation table with four levels, example tasks, common errors, and model responses (this is strong)
- Success criteria
- Generic assessment guidance in the study scope section

**What's still missing:**
- Baseline retrieval (what do pupils already know?)
- Hinge questions (mid-lesson understanding checks)
- Exit tickets (end-of-lesson checks)
- Final assessment rubric distinguishing working towards / expected / greater depth
- Misconception checks (e.g. "Is the Amazon a country or a region?", "Does hot always mean dry?", "Do all people in rainforest regions live the same way?")

**Note:** The differentiation table is genuinely good — but it describes what performance looks like, not how to measure it. It's a reference tool, not an assessment system.

---

### 5. Actual scaffolds for KS2 learners
**Status: Genuinely missing**

The planner itself flags "Learner scaffolding" as thin/missing. This is correct.

**What's needed:**
- Sentence stems ("The region is located in…", "One important physical feature is…", "This affects how people live because…", "Compared with the UK region, this place is…")
- Comparison frames
- Vocabulary supports
- Map annotation prompts
- Structured note-taking templates
- Worked examples
- Model paragraphs
- Chunked tasks

Without this, the planner serves the teacher's brain but not the pupils' learning.

---

### 6. Access and inclusion
**Status: Genuinely missing**

The planner admits this. No SEND considerations, EAL support, or adaptive strategies.

**What's needed:**
- Reduced text versions
- Visual word mats with definitions and pictures
- Map-first teaching before dense prose
- Oral rehearsal before writing
- Options for spoken recording instead of long writing
- Chunked success criteria
- Retrieval supports
- Pre-taught vocabulary
- Explicit background knowledge activation

Routes needed for: weaker readers, EAL pupils, SEND, working-memory difficulties, pupils who struggle with writing volume, pupils who need visual structure.

---

### 7. Better content control (vocabulary)
**Status: Thin/present — but the problem is real**

The planner *does* include:
- Key vocabulary in the primary concept (16 terms)
- A vocabulary word mat (85+ terms)
- A knowledge organiser with key terms (9 terms)

**The problem:** The word mat is entirely empty (no definitions), and the 85+ term list is bloated and unfocused. Many terms are not central to this specific unit (e.g. extensive OS/grid-reference language). This is cognitive clutter for a Year 5/6 class.

**What's needed:** Tiered vocabulary:

**Core vocabulary for this unit (~13 terms):**
region, continent, climate, biome, rainforest, settlement, trade, indigenous, biodiversity, deforestation, compare, physical geography, human geography

**Useful supporting vocabulary (~6 terms):**
Equator, latitude, tropical, tributary, natural resource, export

**Not central right now:**
Much of the OS/grid-reference language, unless deliberately built into the sequence.

## Priority Fixes (in order)

### If you could only fix three things:

1. **Lock the region** — Pick one actual place. Everything else depends on this.
2. **Define the final assessed output** — Say exactly what pupils must produce.
3. **Build the six lessons backwards from that output** — Each lesson teaches a necessary piece of knowledge or skill needed for the final task.

### Then:

4. Populate vocabulary with definitions, tiered by importance
5. Add scaffolding (sentence stems, comparison frames, worked examples)
6. Design assessment architecture (retrieval starters, hinge questions, exit tickets, rubric)
7. Specify access and inclusion routes

## Ideal Lesson Output Schema

For each of the 6 lessons, the output should include:

```
LESSON IDENTITY
  - Lesson number, title, enquiry sub-question
  - Link to overall enquiry

KNOWLEDGE
  - 3-5 core facts
  - 1-2 big ideas
  - 1 likely misconception

VOCABULARY
  - 5-8 lesson-specific terms
  - Child-friendly definitions
  - Pronunciation guidance if useful

TEACHER INPUT
  - Key teaching points
  - Map/image/data set to use
  - Worked example

PUPIL TASK
  - Independent task
  - Scaffolded version
  - Challenge version

ASSESSMENT
  - Retrieval starter
  - Hinge question
  - Exit ticket
  - Marking cues

INCLUSION
  - Oral route
  - Visual route
  - Reduced writing route
  - Vocabulary support

OUTPUT
  - What pupils hand in or present
  - What counts as success
```
